# 报备平台第二批整改优化点汇总

> 来源：`报备平台优化2.docx`、`资质导入模板-调整.xlsx`  
> 整理日期：2026-08-09  
> 说明：本文根据客户本次新提供的 Word 反馈和 Excel 调整模板整理，用于产品确认、需求拆分和开发排期。部分内容与上一批反馈存在延续关系，本文重点记录本次新增或进一步明确的整改优化点。

## 一、总体问题概览

本次客户反馈主要集中在以下方向：

1. **端口信息必填规则仍需放宽**：新建主端口时，部分非关键字段仍被校验为必填，导致主端口创建失败。
2. **子端口分配规则需要支持业务定制**：当前子端口按顺序分配，客户希望支持自定义扩展规则，例如电力行业需要以 `95598` 结尾。
3. **子端口字段命名和拼接逻辑需要明确**：建议将“子端口号”调整为“短信子端口号”，并按“主端口 + 子端口”生成完整短信子端口号。
4. **导入失败、下载失败等错误提示不够可定位**：当前只提示失败，缺少具体失败原因、失败行、失败字段或处理建议。
5. **字段组配置效率需要提升**：运营商字段组字段较长，单个筛选耗时，希望支持字段组批量导入。
6. **资质导入模板需要同步调整**：模板已调整经办人、法人字段顺序，并明确图片内嵌导入、法人字段选填等规则。
7. **端口信息字段组需补充字段**：客户提出端口信息字段组可增加“基础电信企业ID”。

## 三、Excel 模板调整点

### 1. 导入字段结构

`资质导入模板-调整.xlsx` 的“资质导入模板”工作表包含 45 个字段：

- 企业与证件信息：企业名称、单位证件号码、单位证件类型、单位证件图片。
- 责任人信息：责任人姓名、责任人证件类型、责任人证件号码、责任人手机号、责任人证件地址、责任人身份证正面、责任人身份证反面。
- 经办人信息：经办人姓名、经办人证件类型、经办人证件号码、经办人手机号、经办人证件地址、经办人现场照片。
- 法人信息：法人姓名、法人证件类型、法人证件号码、法人证件地址、法人身份证正面、法人身份证反面。
- 短信与业务信息：短信签名、签名类型/来源、短信模板内容、是否签名校验、是否网关签名、模板是否包含变量、模板参数类型、模板参数长度、业务属性、业务类型、业务细类、具体用途。
- 引流信息：引流号码、引流链接、引流号码类型、引流号码用途、引流内容、链接类型。
- 举证附件：签名举证附件、引流号码举证附件、引流链接举证。
- 平台信息：APP/平台名称。

### 2. 字段顺序调整

模板第 14 行备注“标红为已调整字段顺序”。当前标红字段主要为：

- 经办人姓名
- 经办人证件类型
- 经办人证件号码
- 经办人手机号
- 法人姓名
- 法人证件类型
- 法人证件号码

建议导入逻辑以表头名称为准进行字段映射，避免因列顺序调整造成导入失败或数据错位。

### 3. 图片导入说明

“填写说明”工作表明确提出：

- 图片列用于存放资质证明图片。
- 图片可通过“插入图片 -> 放置在单元格中”添加，也可直接拖入图片列单元格。
- 系统会自动提取每行单元格内嵌图片，并与对应字段关联。
- 支持 PNG、JPEG、GIF、BMP、WEBP，单张不超过 10MB。
- 支持图片的列包括：单位证件图片、责任人身份证正面/反面、法人身份证正面/反面、签名举证附件、引流号码举证附件、引流链接举证、经办人现场照片。

## 四、建议拆分的需求项

### 1. 端口信息必填规则与错误提示优化

建议处理范围：

- 企业接入机房及设备
- 运营商接入机房及设备
- 授权书
- 端口开通日期、授权开始日期、授权截止日期
- 集团编码、所属地区、其他接入机房说明等补充信息

建议原则：

- 主端口创建所需最小字段集应尽量收敛，只保留真正用于唯一识别和核心关联的字段。
- 非核心材料字段默认选填，可在导出或报备前进行完整性提醒。
- 创建失败时必须展示具体失败原因，而不是统一提示失败。

### 2. 子端口生成与短信子端口号规则

建议将子端口相关概念拆清：

- 主端口号：例如 `10690010`。
- 子端口扩展码：例如 `103909` 或满足行业后缀规则的扩展码。
- 短信子端口号：主端口号 + 子端口扩展码，例如 `10690010103909`。

建议支持的生成能力：

- 按范围随机生成，例如 `100001-199999`。
- 按顺序生成，兼容现有逻辑。
- 按固定后缀生成，例如必须以 `95598` 结尾。
- 按运营商、行业或字段组配置默认生成规则。
- 按“主端口 + 子端口扩展码”维度做永久唯一校验。

### 3. 导入失败定位与错误报告

建议导入失败时返回结构化错误信息：

- 失败行号。
- 失败字段。
- 当前填写值。
- 失败原因。
- 修复建议。
- 是否可跳过该行继续导入。

建议支持下载错误报告，便于客户批量修正 Excel。

### 4. 字段组批量导入/导出

建议新增字段组批量维护模板，至少包含：

- 字段组名称。
- 模块类型，例如资质字段组、端口信息字段组、报备导出字段组。
- 字段名称。
- 字段编码。
- 字段顺序。
- 是否启用或是否选中。

导入时建议校验字段编码是否存在、字段顺序是否重复、字段组名称是否重复，并给出可定位的错误报告。

### 5. 资质导入模板同步改造

建议同步处理：

- 平台下载的模板更新为本次调整后的字段顺序和填写说明。
- 导入解析按表头匹配，不依赖固定列序。
- 法人证件相关字段默认选填。
- 单元格内嵌图片提取能力与模板说明一致。
- 图片大小、格式、缺失图片、图片无法解析等异常需要可定位提示。

### 6. 端口信息字段补充

建议在端口信息相关字段中新增：

- 基础电信企业ID

需要同步影响范围：

- 后端字段定义或数据模型。
- 端口信息新增/编辑表单。
- 字段组可选字段。
- 导出字段映射。
- 导入或批量维护模板。
- 报备导出模板。

## 五、建议优先级排序

### P0：优先修复，影响核心流程或数据正确性

- 新建主端口非必要字段必填导致创建失败。
- 主端口创建失败缺少明确错误原因。
- 子端口生成规则支持业务定制，并保证唯一性。
- “短信子端口号”命名和主端口 + 子端口拼接逻辑统一。
- 资质导入失败需要明确失败行、字段和原因。
- 资质导入模板字段顺序调整后，平台导入解析不能错位。
- 法人证件相关字段默认选填。
- 端口信息字段组新增“基础电信企业ID”。

### P1：近期优化，提升配置效率和材料完整性

- 报备文件下载失败原因细化，并支持重试或重新生成。
- 字段组支持批量导入/导出。
- Excel 单元格内嵌图片自动提取并关联字段。
- 图片导入失败时提供具体原因和错误报告。

### P2：体验增强，降低长期维护成本

- 按运营商、行业或字段组保存默认子端口生成规则。
- 字段组导入模板支持字段搜索、字段校验和导入预览。
- 导入模板下载页展示版本号和更新说明。

## 六、待业务确认事项

1. 新建主端口的最小必填字段集是什么？哪些字段只需要在导出前提醒补全？
2. “企业接入机房及设备”“运营商接入机房及设备”“授权书”是否默认改为选填？
3. 子端口生成是否需要同时支持范围随机、顺序生成、固定后缀三种模式？
4. 电力行业 `95598` 结尾规则是固定需求，还是一种可配置规则示例？
5. “短信子端口号”是否正式作为页面和导出表头命名？
6. 短信子端口号是否始终等于“主端口号 + 子端口扩展码”？
7. 字段组批量导入模板由客户维护字段名称，还是必须使用系统字段编码？
8. “基础电信企业ID”的数据来源、填写规则和导出位置是什么？
9. Excel 内嵌图片是否必须支持全部列，还是优先支持资质证件类图片？
10. 导入失败时是否允许部分成功、部分失败，还是必须整批回滚？

## 七、建议验收清单

- 新建主端口时，非核心字段为空不会阻塞创建。
- 主端口创建失败时，前端展示明确失败原因和字段定位。
- 子端口可按范围、顺序或固定后缀规则生成。
- 生成的子端口在同一主端口下永久唯一，不会重复使用。
- 页面和导出文件中能清晰区分主端口号、子端口扩展码、短信子端口号。
- 短信子端口号能按主端口号 + 子端口扩展码正确生成。
- 资质导入失败时能定位到失败行、字段、原因和修复建议。
- 平台下载的资质导入模板与本次调整后的模板字段一致。
- 导入逻辑按表头识别字段，调整列顺序后仍能正确导入。
- 法人证件类型、法人证件号码、法人证件地址默认选填。
- Excel 单元格内嵌图片可被提取并关联到对应资质字段。
- 字段组支持通过模板批量导入和导出。
- 端口信息字段组可选择并导出“基础电信企业ID”。
- 报备文件下载失败时展示明确原因，并支持重试或重新生成。
